      Mi diccionario · corrige palabras que se escriben mal
      
Se aplica después de transcribir. Una regla por línea: lo que escribe Whisper => lo que querés que diga. Una palabra sola (sin =>) sirve para nombres propios y términos técnicos: se corrige si suena parecida. Las líneas que empiezan con # son comentarios. Se guarda en este dispositivo; no pongas nombres de pacientes.
